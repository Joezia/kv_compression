## 范围与预算

- 仅使用当前授权的物理 GPU 1，`CUDA_VISIBLE_DEVICES=1`、batch=1；执行前复核占用，不使用 GPU 0，不杀其他进程。
- 主模型固定为 `Qwen/Qwen3.5-9B`。使用文本专用 CausalLM 路径；模型、tokenizer、数据、harness 与 codec 均固定实际 revision/version。
- 官方配置预期为 8 层 full attention 和 24 层 linear attention。M0 必须核实运行时的实际 layer type、state kind、dtype、shape、stride 和字节数；运行时事实优先。
- 先用 128–256 tokens 做缓存结构审计，再约 2K tokens 跑通闭环；主体目标为可用的 8K 请求，16K 只在 M1/M2 资源实测允许时加入。32K 本周延期。
- 核心对照为未压缩、raw-byte ANS、按实际元素宽度分路的 byte-lane ANS、zstd；块大小为 64 KiB 和 256 KiB。BF16 使用两路，FP32 使用四路，禁止改变原 dtype。
- 模型权重下载约 19.3 GB、AgentX 数据约 1.85 GB；含环境的新增磁盘预算不超过 35 GiB。有效原始状态目标 1–4 GiB，所有原始中间数据硬上限 10 GiB。
- GPU 显存警戒线 44 GiB；CPU codec 默认最多 16 核、64 GiB RAM。总 GPU 预算不超过 9 GPU-hours。
- 选择请求时只看会话、分支和长度，必须先于压缩结果。完整请求、position-0 prefix-sampled 与 proxy 分开标注。

本周不做 Qwen2.5、额外模型、低比特权重/KV 量化、20+ 模型扫描、第二张 GPU、AMD/GPU ANS kernel、serving/offload 系统改造或大量空模块。低比特权重压缩仅在 README 登记为待确认分支。

## 数据、缓存与统计口径

AgentX 数据固定为 `semianalysisai/cc-traces-weka-062126@23f152f6f0f9399a85901b89a6458def0ef16729`。优先使用 AIPerf 0.13.0 的公开接口；若与固定数据不兼容，改用已核实的 commit `fd38d2454e826dffa539c49dc64eab2accf911c6` 并记录原因。request/branch path 从 trace 结构派生，不能假设可选字段总存在。

缓存提取不硬编码全层 K/V：

- full-attention 层提取实际保存的 key/value；
- linear-attention 层提取所有初始化的 recurrent/convolution state；
- 未知的非空持久 tensor 必须 fail closed；
- K/V 才记录 token span 和 unique-prefix；recurrent/conv 记录 terminal-after-prefill 语义，不伪造逐 token 范围；
- 每个请求默认独立前向，未证明等价前不复用或裁剪 recurrent state；
- 每个 tensor 独立分块，不跨 layer/state 拼接。

总体压缩比使用 `sum(raw_bytes) / sum(compressed_total_bytes)`，其中 total 包含 payload、概率表、header、索引和 padding。必须输出 KV-only snapshot、KV-only unique-prefix、complete-persistent-state snapshot 及各 state kind 明细。理论/经验熵只能用于解释，不能称为 ANS 实测压缩率。
